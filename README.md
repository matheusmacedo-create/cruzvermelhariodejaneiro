# CVB Links

Central institucional de acessos da Cruz Vermelha Brasileira — Rio de Janeiro.

## Desenvolvimento

1. Copie `.env.example` para `.env.local` e configure o Supabase.
2. Instale as dependências com `npm install`.
3. Inicie com `npm run dev`.

Rotas principais: `/rio` (página pública) e `/admin` (painel administrativo).
